# Apps Script Intro: Macros and Funcstions

This repository exists solely so I can familarize myself with Apps Script

## Commit Conventions
| Tag | Purpose |
| --- | --- | 
| `feat` | add functionality | 
| `fix` | fix a bug |
| `refactor` | change code structure without changing code behaviour |
| `perf` | improve performance | 
| `docs` | documentation | 
| `chore` | maintenance |
